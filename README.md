# Lovebirds Dating App - Admin Features

## Admin Features

### User Approval
- **View Pending Users**: Access the list of users who have registered but are pending approval.
- **Approve Users**: Grant access to approved users, enabling them to fully use the app.
- **Reject Users**: Reject users who do not meet the platform’s criteria or guidelines.

### User Management
- **Delete Users**: Remove user accounts from the system as needed. This action is irreversible and should be used with caution.

### Payment Management
- **Approve Payments**: Review and approve payments made by users. Ensure that transactions are valid and comply with the platform’s policies.

### User Rejection
- **Reject Users**: Identify and reject users who do not meet the platform’s standards or who violate terms of service.

## How to Access Admin Features

1. **Login**: Use your admin credentials to log in to the admin dashboard.
2. **Navigate to Admin Panel**:
   - Go to the admin dashboard from the main menu or directly access the admin panel URL.
3. **Perform Admin Actions**:
   - Use the appropriate sections to approve or reject users, manage payments, and delete accounts.

## Usage

### Approving/Rejecting Users
1. Access the `User Approval` section.
2. Review pending user registrations.
3. Choose to approve or reject users based on the provided information and your evaluation.

### Managing Users
1. Go to the `User Management` section.
2. Search for the user you wish to delete.
3. Confirm the deletion to remove the user from the system.

### Approving Payments
1. Navigate to the `Payment Approval` section.
2. Review pending payments.
3. Approve payments to process transactions and grant access to premium features.

### Rejecting Users
1. Access the `User Rejection` section.
2. Review user profiles that may not meet the platform’s criteria.
3. Reject users accordingly and provide reasons if necessary.
